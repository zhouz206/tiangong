## 快速开始

### 1. 访问天工

打开浏览器访问：http://localhost:3000

### 2. 创建第一个项目

1. 点击"新建项目"
2. 选择项目模板（软件开发/内容创作/数据分析）
3. 填写项目名称和描述
4. 点击"创建"

### 3. 配置 Agent

1. 进入项目详情
2. 点击"分配 Agent"
3. 选择需要的 Agent 角色
4. 配置 Agent 参数

### 4. 开始协作

1. 创建任务
2. 分配给 Agent
3. 等待 Agent 执行
4. 查看结果

## 核心概念

### 项目 (Project)

项目是天工的基本工作单元，包含：
- **名称**: 项目名称
- **描述**: 项目描述
- **阶段**: planning/executing/reviewing/completed
- **状态**: active/paused/completed/cancelled
- **进度**: 0-100%

### Agent

Agent 是天工的执行者，有 8 种预置角色：

| 角色 | 职责 | 适用场景 |
|------|------|----------|
| 📋 项目经理 | 协调进度、需求澄清 | 所有项目 |
| 🔍 研究员 | 信息搜集、分析 | 调研项目 |
| 💻 程序员 | 代码编写、调试 | 软件开发 |
| 🎨 设计师 | UI/UX 设计 | 设计任务 |
| ✍️ 文案 | 内容撰写、编辑 | 文档编写 |
| 🔬 审核员 | 质量检查、审查 | 所有产出物 |
| 📊 数据分析师 | 数据处理、可视化 | 数据分析 |
| 📚 知识管理员 | 文档整理、归档 | 项目归档 |

### 任务 (Task)

任务是项目中的具体工作单元：
- **标题**: 任务名称
- **描述**: 任务详情
- **状态**: pending/in_progress/blocked/completed
- **优先级**: low/medium/high/urgent
- **负责人**: 分配的 Agent

### 里程碑 (Milestone)

里程碑是项目的关键节点：
- **名称**: 里程碑名称（如"M1 核心引擎"）
- **进度**: 0-100%
- **状态**: pending/active/completed/blocked

## 使用指南

### 创建项目

1. **选择模板**
   - 软件开发：程序员、测试员、架构师
   - 内容创作：文案、编辑、设计师
   - 数据分析：数据分析师、可视化专家

2. **填写信息**
   ```
   项目名称：SaaS 应用开发
   描述：构建一个现代化的 SaaS 应用，包括前端、后端和数据库
   ```

3. **确认创建**
   - 检查信息
   - 点击"创建项目"

### 分配 Agent

1. **进入项目详情**
   - 点击项目名称

2. **添加 Agent**
   - 点击"分配 Agent"
   - 选择角色
   - 配置参数

3. **查看 Agent 状态**
   - idle: 空闲
   - working: 工作中
   - blocked: 阻塞

### 创建任务

1. **填写任务信息**
   ```
   标题：实现用户登录功能
   描述：实现基于 JWT 的用户登录功能
   优先级：high
   截止日期：2026-03-30
   ```

2. **分配负责人**
   - 选择合适的 Agent
   - 点击"分配"

3. **跟踪进度**
   - 查看任务状态
   - 查看执行日志

### 使用知识库

1. **搜索知识**
   - 输入关键词
   - 查看搜索结果

2. **上传文档**
   - 点击"上传文档"
   - 选择文件
   - 填写分类和标签

3. **管理分类**
   - 技术文档
   - 产品文档
   - 研究报告
   - 流程规范
   - 会议记录

## 最佳实践

### 项目管理

1. **明确目标**
   - 项目开始前明确目标
   - 拆解为可执行的任务

2. **合理分配**
   - 根据任务类型选择合适的 Agent
   - 避免单个 Agent 过载

3. **定期检查**
   - 查看项目进度
   - 及时调整计划

### Agent 协作

1. **上下游协作**
   - 设置任务依赖关系
   - 上游完成后自动触发下游

2. **局部讨论**
   - 相关 Agent 进行私有讨论
   - 用户可查看讨论记录

3. **知识沉淀**
   - 项目完成后自动归档
   - 形成团队知识库

### 质量控制

1. **代码审查**
   - 所有代码必须经过审查
   - P0 问题必须修复

2. **测试覆盖**
   - 单元测试覆盖率≥70%
   - 核心流程必须测试

3. **文档完整**
   - API 文档同步更新
   - 用户文档完整

## 常见问题

### Q: 如何重置项目进度？

A: 在项目设置中点击"重置进度"，确认后项目将回到初始状态。

### Q: Agent 执行失败怎么办？

A: 
1. 查看 Agent 执行日志
2. 检查错误信息
3. 重新分配任务或调整参数

### Q: 如何导出项目数据？

A: 在项目设置中点击"导出数据"，选择导出格式（JSON/CSV）。

### Q: 知识库支持哪些文件格式？

A: 支持 .txt, .md, .pdf, .docx, .json, .yaml 等常见格式。

### Q: 如何邀请团队成员？

A: 在工作空间设置中点击"邀请成员"，输入邮箱地址发送邀请。

### Q: 支持哪些 AI 模型？

A: 
- OpenAI: GPT-4o, GPT-4o-mini, GPT-3.5-turbo
- Anthropic: Claude-3.5-Sonnet, Claude-3-Haiku
- 阿里云：Qwen-Max, Qwen-Plus, Qwen-Turbo
- 本地：Ollama (Llama3, Qwen2.5, Mistral)

### Q: 数据安全性如何保障？

A: 
- 数据加密存储
- API 密钥加密保存
- 支持本地部署
- 定期备份
